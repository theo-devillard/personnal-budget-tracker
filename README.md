# Budget App

Simple, privacy-focused personal budgeting web app.

## Highlights

- Dashboard with overview cards and interactive charts
- Monthly planning, recurring and one-off transactions
- Multi-currency support and local export/import
- PWA-enabled for offline use

## Run

Open `index.html` in a browser:

```bash
open index.html
```

## Tech

- HTML, CSS, JavaScript
- Chart.js for charts
- LocalStorage for persistence

## Quick Start

1. Configure settings
2. Add transactions
3. Review charts and reports

---

Privacy: data is stored locally in the browser.
